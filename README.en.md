# ip-reputation-check

[中文](README.md) | **English**

> Multi-source IP lookup + current-egress verification + use-case node health check. Give an IP or a node, get **verifiable multi-dimensional evidence** and **common-site reachability** — fast.
>
> ⚠️ Positioning: **multi-source screening + evidence grading**, NOT an authoritative risk/security verdict. Free sources are limited; for strict risk control use commercial APIs (MaxMind / IPQualityScore / Spur / VirusTotal / Spamhaus...).

Full example output: [examples/demo.txt](examples/demo.txt) (generated by current code, not hand-written).

## Quick start

```bash
python scripts/ipcheck.py 8.8.8.8            # zero-config by default
python scripts/ipcheck.py 8.8.8.8 --brief    # one-line summary
```

Zero-config gives: geo / ASN / datacenter-proxy-VPN / fraud score / keyless abuse lists / rule score / confidence. Add your own free keys only for extra precision.

## Features

- **17 sources**: geo, ASN, proxy/VPN/hosting, fraud score, abuse lists, RDAP registry, BGP routing, Tor official exit.
- **Traceable evidence**: per-field applicable sources + support/oppose + strength; registry (RDAP) vs routing (BGP) kept apart; `marked VPN != actual VPN`.
- **No misleading**: no data/empty -> `unknown` (never "clean"); DNSBL transient -> unknown; Fake-IP -> DoH fallback trusting hits only; private/reserved skipped locally.
- **Optional real probe**: `probe / node / compare / history` from the egress/proxy, read-only; strictly separates "rule-based" from "measured".
- **Ops**: batch `--file`, CSV, `watch`, source `health`, source-level cache, one-shot `selfcheck`.

## Commands

```bash
python scripts/ipcheck.py check <IP...> [--file F] [--csv out.csv] [--json] [--brief] \
       [--env] [--regions] [--no-platforms] [--refresh] [--interval S] [--only ...] [--gateway URL]
python scripts/ipcheck.py probe  [--proxy URL] [--expect-ip IP] [--only google,openai,x,...] [--json]
python scripts/ipcheck.py node   [--proxy URL] [--expect-ip IP] [--scenario browse|ai|stream|account|call|general] [--save] [--json]
python scripts/ipcheck.py compare --nodes "http://p1,http://p2" [--scenario ai] [--json]
python scripts/ipcheck.py history [--node X] [--scenario ai]
python scripts/ipcheck.py myip | health | stability | watch | open <IP>
python scripts/selfcheck.py     # offline tests + live smoke
```

## Sources (17)

ipinfo, ip-api, ipwho.is (geo/ASN); proxycheck (proxy/VPN); scamalytics (fraud); iphub (proxy; guest or key); AbuseIPDB (key); StopForumSpam, blocklist.de, IPsum (keyless abuse); Spamhaus DNSBL (SBL/XBL/DROP malicious; PBL policy); VirusTotal (optional key); DB-IP, MaxMind GeoLite2 (geo); RDAP, RIPEstat (registry/routing); Tor official exit.

## Confidence & evidence

- Tiers: A (authoritative/commercial) / B (specialised) / C (community/aggregate).
- **Per-field applicable sources** (geo uses geo DBs only; proxy/VPN dedicated DBs; Tor official; abuse lists/community). JSON `evidence` has `sources/applicability/level`.
- **Independence unknown**: without an A-tier source supporting the value, multi B/C agreement caps at "medium" (a temporary conservative rule, **not** a claim that independence is solved).
- High/medium/low is **evidence grade**, not statistical probability. No "accuracy/banned-rate" numbers.

## Cache & time

Per-source raw cache (never the final verdict; re-aggregated with current version). Key = parser-version + source + normalized IP. `fetched_at / data_time / expires_at / served_at / cache_status`; `--refresh` bypasses and penetrates list-level cache; within fallback window -> usable but flagged, beyond -> history only; list sources use real list fetch time; no secrets stored.

## Probe boundaries

Must originate from that IP's egress (`--proxy`); egress≠target is flagged and attribution limited. Only **web/public-API endpoints** (not App login/upload/push); request latency != line ping/loss. Conservative statuses (success-but-unverified / region-restricted / human-verification / auth-required / denied-unknown / rate-limited / connect-failed). Proxy may split by domain/IPv6: egress match is necessary, not sufficient.

## Requirements

Python 3.8+, **no third-party deps**; Windows no-install `dist/ipcheck.exe`. Optional: `maxminddb`; Playwright+Chrome for `--browser`. Optional keys: `IPHUB_API_KEY` / `ABUSEIPDB_API_KEY` / `VIRUSTOTAL_API_KEY` / `IPINFO_TOKEN` / `SCAMALYTICS_USER`+`SCAMALYTICS_KEY` / `GEOIP2_MMDB` / `IPCHECK_GATEWAY` / `IPCHECK_PROXY` / `IPCHECK_CACHE` / `IPCHECK_HISTORY`.

## Compliance

Respect terms of service / API policy / data license; `robots.txt` applies to crawlers only and is not authorization; free sources have rate/commercial terms; proxy credentials are never logged or reported.

## Tests

`python scripts/selfcheck.py` runs all offline suites (core/cache/counterexamples/fixtures/contract/docs/consistency) + live smoke. CI covers Python 3.8/3.10/3.12 + Windows.

## Boundaries

Registry/routing/ASN relatively reliable; city 50–80%; proxy/VPN coverage incomplete; **abuse "no hit" is weak proof**; site fit is rule-based, not measured. Cannot judge "dedicated residential / will be banned / long-term stability" from an IP alone. No throughput/loss, no App functionality testing.
